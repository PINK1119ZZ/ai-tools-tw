🤖 什麼是 AI 語音 Agent？

AI 語音 Agent 是可以打電話、接電話、理解語意並即時回應的自動化系統。和傳統 IVR（按 1 查訂單、按 2 轉客服）不同，Voice AI 能聽懂自然語言、處理複雜查詢、甚至執行訂單修改、預約確認等後端動作。

台灣常見應用場景：

  • 電商：AI 自動接聽「我的包裹到哪了」「可以改地址嗎」，整合物流 API 直接回答
  • 醫療/診所：AI 接聽預約電話，查詢時段、確認候診、發送 LINE 提醒
  • 補習班/教育：家長詢問課程費用、班次，AI 自動篩選並轉接招生人員
  • 催款回撥：AI 撥打欠款客戶、提示繳費期限、提供付款連結
  • 餐廳訂位：電話訂位 AI 查詢空位、確認訂位、發送 Google Calendar 邀請

⚡
Vapi 88 / 100
開發者首選，API 彈性最高，可接入任意 LLM + TTS

Vapi 的產品定位是「Voice AI 基礎設施層」，而非現成解決方案。它讓工程師可以自由組合：選擇自己偏好的 LLM（GPT-5、Claude 4、Gemini、本地 LLaMA）、TTS 引擎（ElevenLabs、Azure Neural TTS、Cartesia、Deepgram Aura）和 STT 工具（Deepgram Nova-3、Whisper Large v3），再透過統一 API 接入通話流程。

這種「樂高積木」設計讓 Vapi 在技術團隊中極受歡迎。2026 年台灣有多家 AI 新創和自動化服務商以 Vapi 為底層構建自家語音產品。

核心功能

  • BYO（Bring Your Own）模型架構：LLM、TTS、STT 均可替換，Latency 可針對需求優化
  • Server URL Webhook：每次對話事件（說話開始/結束/工具調用）均可觸發自訂邏輯
  • Function Calling（工具調用）：AI 通話中即時調用外部 API，執行訂單查詢、日曆預約、資料庫寫入
  • Squad（多 Agent 協作）：一通電話可讓多個 AI Agent 接力處理不同段落，例如先由銷售 Agent 介紹產品，再轉給預約 Agent 確認時段
  • 中文支援：搭配 Azure Neural TTS 台灣普通話語音，延遲 500–700ms，中文發音自然度三者中最高，腔調最接近台灣口音
  • Web 電話：可在網頁嵌入「直接通話」按鈕，無需傳統 PSTN 電話線路

台灣適用評估

Vapi 是台灣有工程師資源的團隊最佳選擇。如果你的場景需要即時存取 Shopify API 查訂單狀態、或是需要在通話中寫入 Google Calendar、或是想用自家微調的 LLM，Vapi 提供最完整的彈性。繁中語音品質是三者中最佳，搭配 Azure 台灣普通話語音幾乎無明顯外國腔。

💡 台灣部署 AI 語音 Agent 實務注意事項

1. 台灣本地電話號碼申請

三大平台本身均不直接提供台灣 (+886) 本地號碼。目前最常見的做法是透過 Twilio 申請台灣市話或 0800 免費電話號碼，再綁定到 Voice AI 平台。Twilio 台灣號碼費用約 $1–3 美元/月，每分鐘通話費約 $0.012–0.02 美元（入站）。若客戶量大，也可考慮向台灣本地電信申請 SIP Trunk（例如中華電信企業方案）並透過 SIP 協議接入 Vapi 或 Bland AI。

2. 個資法合規（台灣《個人資料保護法》）

AI 電話通話涉及錄音，台灣法規要求通話開始前必須告知「本通話將被錄音」。建議在 AI 開場白加入：「您好，本通話將被錄音以提升服務品質，如不同意請掛斷。」三大平台均支援自訂開場語音或文字。此外，通話錄音與逐字稿儲存於境外伺服器，若涉及敏感個資（病歷、財務），需評估是否符合個資法境外傳輸規範。

3. 繁中語音優化技巧

AI 語音 Agent 在繁中環境的常見問題：數字唸法不一致（「一百元」vs「壹佰元」）、成語或業界術語發音錯誤、「捷運」「蝦皮」等台灣特有詞彙。建議在 Prompt 中明確指定用繁體中文回應，並在知識庫中提供常見詞彙的標準唸法示範。使用 Vapi + Azure TTS 的台灣普通話語音時，這些問題發生率最低。

4. 成本控制建議

Voice AI 的隱藏成本主要來自「無效通話」：電話接起後用戶立刻掛斷、無人接聽重撥、惡意長通話。建議設定最大通話時長（Retell 和 Bland 均支援），並在 Prompt 中加入「如果用戶 20 秒未回應，請禮貌結束通話」的指令。實測下來，加入這兩個設定可減少約 30–40% 的無效分鐘數。

❓ 常見問題（FAQ）

Q1. 台灣用戶不會說英文，AI 能全程中文對話嗎？

三大平台均支援全程繁體中文對話，包含繁中 Prompt 撰寫、中文 TTS 語音輸出、中文 STT 識別。建議在 System Prompt 中明確寫「請全程使用繁體中文回應」，並測試幾個台灣常見口語詞彙（「蝦皮訂單」「悠遊卡」「捷運」）確認識別正確率。

Q2. AI 電話客服是否會影響客戶觀感？

關鍵在於透明度和場景適配。明確告知「您正在與 AI 語音助理通話」通常比偽裝成真人更受歡迎——特別是對年輕族群。但對老年客戶或投訴處理場景，建議設計快速轉真人的出口（「如需真人服務，請說『轉接客服』」）。

Q3. 三大平台的語音是否能辨識台語（閩南語）？

目前三大平台的 STT（語音轉文字）對純台語辨識效果均不穩定。建議場景設計以普通話為主，必要時在 Prompt 中加入「如果用戶使用台語，請以普通話回應並請用戶以普通話重複問題」的備援指令。

Q4. 能不能讓 AI 電話直接幫客戶取消訂單？

可以。透過 Function Calling（Vapi）或 Webhook 動作（Bland AI / Retell），AI 可在通話中呼叫 Shopify API 執行訂單取消、地址修改、退款申請。需要注意的是，高風險操作（如退款）建議加入二次確認步驟（「請問您確認要退款 $X 嗎？」）並在系統端記錄操作 Log。

Q5. 三大平台都需要 Twilio 嗎？

取決於你是否需要真實電話號碼。如果只需要「點擊網頁按鈕直接通話（Web Call）」，三大平台均可直接使用，不需要 Twilio。如果需要客戶用電話撥打/接聽，則需要 Twilio 或其他 SIP 電話供應商提供號碼。Retell AI 也提供直接購買美國號碼的選項（$2/月），但台灣號碼仍需 Twilio。
