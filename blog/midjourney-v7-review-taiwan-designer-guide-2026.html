v7 新功能深度解析

① Draft Mode — 草圖模式，讓你的 GPU 點數用更久

這是 v7 最受歡迎的新功能。Draft Mode 使用更輕量的模型快速生成草圖，速度比標準模式快 4 倍，消耗的 GPU 分鐘數也只有 1/4。

對台灣設計師的實際意義：每個月 $10 方案的 200 張額度，在 Draft Mode 下可以「試方向」試到 800 張。確定方向後再用標準模式出最終稿，省到一倍以上的預算。

💡 Draft Mode 使用技巧：
在提示詞後加 --draft 即可啟用。例如：
minimalist product photo, white background, ceramic vase --draft --ar 1:1
確認構圖滿意後，再移除 --draft 生成高畫質版本。

② 角色一致性（Character Reference / --cref）大升級

v6 的 --cref 已經很好用，但有個痛點：角色跨場景時面孔容易飄移，頭髮顏色或服裝細節常有誤差。v7 在這方面做了顯著改善。

實際測試：同一個角色圖，連續生成 10 張不同場景（辦公室、咖啡廳、戶外、夜晚），臉部特徵一致率從 v6 的約 70% 提升到 v7 的約 88%。對於做 IP 角色、Line 貼圖、漫畫連載的台灣創作者，這個升級非常實用。

③ 長提示詞支援——終於能說清楚你要什麼

v6 建議提示詞簡潔（60 字以內），太長反而效果不佳。v7 改進了提示詞解析模型，支援 150 字以上的長段落描述。

這對台灣用戶的影響是：你可以把繁中需求先用 ChatGPT 翻譯成細緻的英文描述，再貼到 v7，執行準確度大幅提升。

④ 獨立網頁版正式上線

終於不用 Discord 了！Midjourney 的獨立網頁版（midjourney.com）在 v7 時代已完全成熟，支援：

  • 圖庫管理（按風格、日期、關鍵字搜尋）
  • 批次生成與佇列管理
  • 風格收藏（Style Tuner 結果可存檔）
  • 直接從網頁下載高解析原圖
  • 帳單與用量管理介面

繁中提示詞實戰技巧

Midjourney 的底層不是大語言模型，對中文提示詞的解析能力遠不如 DALL-E 3。但有了正確的工作流程，中文用戶完全能發揮 v7 的全部潛力。

工作流程：ChatGPT 翻譯 + Midjourney 生成

在 ChatGPT 輸入這個提示詞模板：

// ChatGPT 翻譯提示詞模板 幫我把以下圖像描述翻譯成適合 Midjourney v7 的英文提示詞， 要包含：主體描述、風格、光線、情緒、相機視角、畫質參數。 請直接輸出英文提示詞，不要解釋。

我的需求：[在這裡填入你的中文描述]

② 台灣在地風格插畫

// 台灣城市夜景插畫 Taiwan night market street scene, illustrated style, warm neon lights, scooters and food stalls, rainy evening, Studio Ghibli inspired, detailed cityscape, cinematic atmosphere, 16:9 --ar 16:9 --stylize 500 --v 7

💡 v7 必知參數速查：
--ar 比例（16:9 橫、9:16 直、1:1 方）
--stylize [0-1000] 藝術風格強度（預設 100）
--v 7 指定 v7 模型
--niji 6 動漫風格模型（插畫/角色設計首選）
--draft 草圖模式（快速省點數）
--cref [圖片URL] 角色參考圖
--sref [圖片URL] 風格參考圖

常見問題 FAQ

Q1：Midjourney v7 和 v6 差在哪裡？

主要升級包括：更強的人臉一致性（同一角色跨圖保持外觀）、更精準的提示詞解析（長句也能正確執行）、原生 Draft Mode（快速低成本出草稿）、以及更細膩的材質與光影表現。整體比 v6 的細節豐富度提升約 30%。

Q2：Midjourney v7 可以用中文提示詞嗎？

Midjourney 本身對中文提示詞的支援有限，直接用繁體中文效果不穩定。最佳做法是先用 ChatGPT 把繁中描述翻譯成精準英文提示詞，再輸入 Midjourney，成功率大幅提升。本文上方附有完整的提示詞翻譯技巧和範例。

Q3：Midjourney 生成的圖片可以商業使用嗎？

付費方案（Basic $10/月起）均可商業使用，但 Basic 方案有年收入 $20,000 美元的限制。Standard 以上方案無收入限制。若需要完全私密（不被他人看到生成紀錄），需 Pro 方案以上的 Stealth Mode。

Q4：Midjourney 有免費版嗎？2026 年還能免費試用嗎？

Midjourney 目前（2026 年）已無永久免費方案。偶爾會針對新用戶開放 25 次免費試用，但不穩定。最低入門方案為 Basic Plan $10/月（約 NT$320），可生成約 200 張圖，建議先用一個月試試看再決定是否升級。

Q5：Midjourney v7 適合電商產品圖嗎？

非常適合！v7 的寫實材質渲染能力大幅提升，適合生成產品情境圖、生活風格照（lifestyle shots）、包裝視覺概念圖。但若需要精確展示你的實際產品，建議搭配 --cref（角色參考）功能上傳產品照，或用 Vary Region 局部修改。

Q6：Midjourney、DALL-E 3、Stable Diffusion 2026 年哪個最好？

各有所長：Midjourney v7 → 美學畫質最頂、電影感最強、設計師首選。DALL-E 3 → 繁中理解最佳、對話式最直覺、不想學提示詞的人首選。Stable Diffusion → 完全免費、本地端離線、技術宅和隱私重視者首選。台灣多數設計師和自媒體創作者以 Midjourney 為主力。

Q7：不用 Discord 可以使用 Midjourney 嗎？

可以！Midjourney 在 2025 年底推出了獨立網頁版（midjourney.com），不再強制需要 Discord。網頁版介面更直覺，支援圖庫管理、批次生成、風格收藏等功能，台灣用戶直接用瀏覽器即可，不需要先加入 Discord 伺服器。

Q8：台灣用信用卡可以訂閱 Midjourney 嗎？

可以。Midjourney 接受 Visa、Mastercard、American Express 等國際信用卡。台灣的信用卡通常可以直接訂閱，費用以美元計算，由銀行按當日匯率換算台幣。部分銀行的刷卡可能會有海外交易手續費（約 1.5%）。
