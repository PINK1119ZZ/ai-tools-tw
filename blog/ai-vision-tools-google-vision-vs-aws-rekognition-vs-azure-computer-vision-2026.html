🟦 Google Cloud Vision AI 深度評測

Google Cloud Vision AI OCR 冠軍

Google 的電腦視覺 API 建立在全球最大規模的影像訓練資料之上。Vision API 提供標籤偵測、物件定位、OCR、臉部偵測、地標識別、Logo 辨識、圖片安全性分類等一站式功能，而 AutoML Vision 讓非 ML 工程師也能用自有資料訓練客製化模型。

🔑 核心功能亮點

  • Document AI / OCR：繁體中文辨識準確率業界最高，支援發票、合約、名片、手寫字
  • Product Search：電商商品以圖搜圖，上傳商品圖即可建立可搜尋商品目錄
  • SafeSearch：5 個維度分類（成人/暴力/醫療/詐欺/惡搞），平台內容審核必備
  • AutoML Vision：上傳標注圖片，低程式碼訓練客製物件偵測模型
  • Vertex AI Vision：整合 Gemini 多模態，一個 API 同時分析影像+文字描述

🟠 AWS Rekognition 深度評測

AWS Rekognition 人臉辨識冠軍

AWS Rekognition 是亞馬遜雲服務的電腦視覺旗艦，最強項是人臉搜尋（Face Search）和影片串流即時分析。它提供圖片和影片兩大 API 集合，可偵測物件、場景、不當內容、人臉、文字，並支援名人辨識和客製化標籤訓練。

🔑 核心功能亮點

  • Face Search（1:N 人臉搜尋）：建立人臉集合（Collection），從影片/照片即時匹配身份，KYC 驗證、考勤打卡必備
  • Video Analysis（即時串流）：搭配 Kinesis Video Streams，對 RTSP 監控串流做人流統計、安防事件觸發
  • Content Moderation：多類別有害內容偵測，精細度高，UGC 平台、成人內容過濾首選
  • Custom Labels：上傳標注圖片，幾十分鐘訓練工廠品管、零售商品的客製偵測模型
  • PPE Detection：自動偵測工作人員是否佩戴安全帽/口罩/手套，製造業工安管理

🟦 Azure Computer Vision 深度評測

Azure Computer Vision Microsoft 生態整合王

Azure Computer Vision 是微軟 Azure AI Services 的核心之一，2026 年以 Florence 基礎模型為底層大幅升級，支援圖說生成（Image Captioning）、密度圖、背景移除、光學字元辨識（Read API）。搭配 Custom Vision，不懂機器學習的業務人員也能在瀏覽器內訓練自己的圖像分類模型。

🔑 核心功能亮點

  • Read API（OCR）：多頁 PDF/TIFF 非同步辨識，支援列印與手寫，繁體中文支援良好
  • Image Analysis 4.0（Florence）：同時輸出物件偵測、標籤、圖說、密度圖，一個 API 搞定
  • Custom Vision：瀏覽器 UI 拖拉標注，幾百張圖就能訓練客製模型，匯出 TFLite/ONNX 在地端推論
  • Face API：臉部偵測、情緒分析、年齡預估，整合 Azure Active Directory 做員工門禁
  • Background Removal（預覽）：一鍵去除圖片背景，電商商品圖處理效率大增

🎯 6 大使用場景：台灣企業怎麼選？

🛒 場景 1｜電商商品圖自動分類 + 以圖搜圖

推薦：Google Cloud Vision AI（Product Search）

台灣 PChome、蝦皮賣家每天上架數百張商品圖，手動分類耗時費力。Google Product Search 讓你上傳商品圖自動建立可搜尋目錄，加上繁體中文 OCR 辨識商品標籤文字，是電商選品、防盜版監控的利器。

🏭 場景 2｜製造業品管瑕疵檢測

推薦：AWS Rekognition Custom Labels 或 Azure Custom Vision

台灣科技製造業（PCB 板、金屬零件、食品包裝）需要即時偵測表面瑕疵。Custom Labels 和 Custom Vision 都提供低程式碼訓練界面，只需幾百張標注圖就能訓練。Azure Custom Vision 可匯出 ONNX 模型在產線工控電腦本地推論，不依賴雲端，延遲低於 50ms。

📋 場景 3｜文件數位化（發票/合約/名片）

推薦：Google Cloud Vision AI（Document AI）

會計事務所、法律事務所每月處理大量紙本文件。Google Document AI 對繁體中文發票（含電子發票 QR Code）、合約條款辨識準確率最高，搭配 GCP BigQuery 可直接做財務分析，省去人工打字。

🏪 場景 4｜零售門店人流分析 + 安防監控

推薦：AWS Rekognition（Streaming Video Events）

連鎖超商、百貨公司需要即時分析進店人流、顧客動線，甚至結合人臉比對做 VIP 識別。Rekognition 搭配 Kinesis Video Streams 可對 RTSP 監控攝影機直播做即時分析，觸發 Lambda 事件（如：等待超過 5 分鐘則通知收銀員）。

🏥 場景 5｜醫療/保險 KYC 身份驗證

推薦：AWS Rekognition（Face Liveness）或 Azure Face API

台灣保險公司遠端投保、銀行開戶的 KYC 流程需要活體偵測（liveness detection）防假照。Rekognition Face Liveness 是目前 API 中活體偵測最成熟的方案；Azure Face API 整合 Entra ID 可直接與企業 SSO 對接，適合有 Microsoft 生態的金融機構。

💻 場景 6｜新創 / 個人開發者低成本試驗

推薦：Google Cloud Vision AI（免費額度最多）或 Azure（Custom Vision 免費 10K 預測）

台灣新創和接案工程師想快速 PoC（概念驗證），Google 每月 1,000 次多項功能免費，Azure Custom Vision 預測每月 10K 次免費，都夠撐 MVP 階段。AWS 的 5K/月免費雖然也夠，但帳號管理和 IAM 設定對初學者門檻稍高。

🔐 台灣企業使用注意事項

  • 個資法（PDPA）合規：人臉辨識涉及生物特徵資料，在台灣需符合《個人資料保護法》第6條特種個資規定，務必在隱私政策說明用途並取得同意
  • AWS 無台灣節點：選 ap-northeast-1（日本）延遲約 50-80ms；若需更低延遲可考慮 GCP 台灣節點（約 5-15ms）
  • Azure Face API Limited Access：部分人臉辨識功能（人臉辨識、相似度比對）需向微軟申請 Limited Access，審核約 2-4 週，台灣企業記得提早申請
  • 支付方式：三平台均支援信用卡（Visa/Mastercard）；GCP 支援雲端市場購買（AWS Marketplace/Azure Marketplace）；大量採購可洽各平台台灣業務窗口
  • 資料主權：若處理台灣金融/醫療資料，建議指定亞太資料中心，並確認各平台的資料處理協議（DPA）符合金管會/衛福部要求
  • 繁中模型訓練：Custom Labels/Custom Vision 訓練資料若含繁體中文文字，建議先用 Google OCR 預處理，再餵入訓練，可提升準確率

🤔 AI 影像辨識 API 常見問題（FAQ）

Q1｜台灣小型電商用哪個最划算？

預算有限且主要需求是商品圖標籤和繁體中文 OCR，Google Cloud Vision AI 最划算。每月 1,000 次多項功能免費，超量後每千次 $1.50，繁體中文準確率最高，台灣節點延遲最低，是電商最高 CP 值的選擇。

Q2｜製造業品管用哪個自訓模型比較好？

Azure Custom Vision 若有 Microsoft 生態，是首選；它能匯出 ONNX 模型在本地機台推論，不依賴網路。若已用 AWS，Rekognition Custom Labels 也很成熟，但按小時計費，品管模型最好只在需要時啟動。

Q3｜人臉辨識在台灣合法嗎？

技術本身合法，但應用必須符合《個人資料保護法》第6條。生物特徵屬特種個資，需有特定目的且當事人明確同意，不得在未告知的情況下蒐集。公共場所大規模部署人臉辨識屬高風險，建議先洽詢法律顧問。

Q4｜三個平台可以同時使用嗎？

完全可以，許多台灣企業採用混合策略：用 Google OCR 處理文件、AWS Rekognition 做門禁人臉，再用 Azure Custom Vision 跑客製品管模型。各取所長，但需要管理三個雲帳戶，建議搭配 Terraform 或 Pulumi 統一 IaC 管理。

Q5｜不想用雲端 API，有其他方案嗎？

可考慮開源方案：YOLO v11（物件偵測）、PaddleOCR（繁中 OCR 效果極佳）、InsightFace（人臉辨識）。開源方案一次性訓練成本，後續無 API 費用，適合大量推論；但需要 GPU 主機和機器學習工程師維護，適合有技術能力的中大型企業。

Q6｜影片監控分析要用哪個？

AWS Rekognition Streaming Video Events 是目前雲端 API 中影片串流分析最完整的方案，支援 Kinesis Video Streams 即時處理，可設定事件觸發（偵測到人→發 SNS 通知）。如果只需要離線影片分析（非即時），Google Video Intelligence 和 Azure Video Indexer 也都很好用。

Q7｜需要什麼技術背景才能串接 Vision API？

基本 Python 能力（會用 requests 或各平台 SDK）即可。三大平台都有 Python SDK 和豐富文件，一般工程師 1-2 天就能完成基礎串接。自訓模型（Custom Labels/Custom Vision）有 UI 界面，非工程師的產品/品管人員也能操作標注和訓練，只有模型部署階段需要工程師協助。

Q8｜台灣有哪些場景是特別值得做的？

台灣市場特別有潛力的場景包括：電子發票辨識自動化（繁中+QR Code）、蝦皮/MOMO 商品圖自動審核（SafeSearch 過濾）、工廠 AOI 視覺檢測升級（Custom 模型取代昂貴的傳統工業相機方案）、診所病歷表單數位化（OCR + FHIR 整合）。這些場景競爭對手少，容易做出差異化。
